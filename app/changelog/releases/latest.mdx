# Latest Release

## Version 2.1.0 - January 2024

### 🎉 New Features

- **Enhanced Webhook System**: Improved webhook delivery reliability and added retry mechanisms
- **New Meter Types**: Added support for histogram and gauge meter types
- **Bulk Operations API**: New endpoints for batch processing of products and invoices

### ✨ Improvements

- Reduced API response times by 30%
- Improved error messages with more context
- Enhanced documentation with more code examples

### 🐛 Bug Fixes

- Fixed issue with invoice generation for subscriptions
- Resolved pagination bug in products list endpoint
- Fixed timezone handling in usage reports

### 🔒 Security

- Updated dependencies to address security vulnerabilities
- Enhanced API key validation

### 📚 Documentation

- Added migration guide from v2.0.0
- Updated API reference with new endpoints
- Added troubleshooting section
